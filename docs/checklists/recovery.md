# Recovery Checklist

- [ ] New dispatch is paused.
- [ ] Git orchestration files were read before chat/transcript guesses.
- [ ] CCM room status, screen/nav, transcript, Agent Resume Identity, and Slack room facts were inspected for non-terminal workers.
- [ ] Duplicate Orchestrators were reconciled by human choice before writes.
- [ ] Each worker is moved only to a state proven by durable files plus external facts.
- [ ] Recovery Note is written and `state.md` records the next single action.
